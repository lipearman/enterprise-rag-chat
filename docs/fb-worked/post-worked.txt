[รูป 1] ① Intent Router
ไล่ keyword ทีละกลุ่ม staff ✗ → fact ✗ → claim ✗ → ได้ knowledge
เทียบไม่เกิน 30 × 23 = 690 ครั้ง ไม่ต้องใช้ AI และดึง company_facts ด้วย SQL ไปพร้อมกัน

[รูป 2] ② Embedding
u = (2, 1, 0.5, −1) → ‖u‖ = √6.25 = 2.5 → q = (0.8, 0.4, 0.2, −0.4)
ถ้าเจอ NaN: หั่นเป็น 3 ช่วง ทิ้งช่วงที่เสีย เฉลี่ยได้ (0.7, 0.4, 0.3, 0) แล้วหารด้วย 0.8602

[รูป 3] ③ IVFFlat
cos กับ centroid: μ₁ = 0.98, μ₂ = 0.02, μ₃ = −0.08 → เปิดเฉพาะกลุ่ม 1 ส่วนเอกสารข่าวและสุขภาพไม่ถูกเทียบเลย

[รูป 4] ④ Cosine
d₁ = 0.98 / 0.9874 = 0.9925 (7°)
d₂ = 0.70 / 1 = 0.7000 (45.6°)
d₃ = 0.52 / 0.8832 = 0.5888 (53.9°)

[รูป 5] ⑤ Top-k + τ = 0.40
เอกสารผ่านครบ 3 ชิ้น ส่วน FAQ f₂ = 0.35 ถูกตัด เพราะ 69.5° > 66.4° และ ‖q−f‖² = 1.30 > 1.2

[รูป 6] ⑥ Context
